# Задание 2 — API-пайплайн: данные → LLM → результат

### Описание задачи
Скрипт автоматизирует обработку отзывов покупателей интернет-магазина одежды. Он читает данные из CSV-файла, отправляет текст отзыва в нейросеть (GPT-4o-mini через API OpenRouter) и сохраняет структурированный анализ в итоговую таблицу.

**Что реализовано:**
* Чтение и автоматическая очистка данных от пустых отзывов.
* Формирование запроса к LLM для получения ответа строго в формате JSON.
* Парсинг ответа и сохранение результатов в новый файл.

### Инструкция по запуску
1. **Установите библиотеки:**
   ```bash
   pip install pandas openai
2. **Вставить ключ от OpenRouter в переменную api_key**
3. **Запустите код:**
   ```bash
   python main.py
